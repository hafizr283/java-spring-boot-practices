# Spring Boot Mini Projects

Small Spring and Spring Boot examples for practicing dependency injection, component scanning, REST APIs, and application configuration.

## Projects

| Project | Description | Documentation |
| --- | --- | --- |
| `01_Calculator` | Spring Boot REST calculator with JSON request/response handling and troubleshooting notes. | [README](01_Calculator/README.md) |
| `02_notification_payment_spring_core` | Plain Spring Core order-processing example using component scanning, constructor injection, payment implementations, notifications, and bean lifecycle callbacks. | [README](02_notification_payment_spring_core/README.md) |

Each project is self-contained. Open its directory and follow the linked README for build and run instructions.
